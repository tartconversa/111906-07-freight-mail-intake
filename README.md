# 展品运输邮件的原件采集与入场交接
本项目目前提供隔离的本地来源和原始合成资料，业务采集程序尚未实现。所有姓名、联系方式、证件、费用和机构均为演练数据，不连接实际业务系统。来源服务只响应自身接口或页面操作，不会自动在来源与接收方之间搬运资料。
## 环境和运行
使用 Python 3.11，依赖固定在 requirements.txt。准备环境时执行 `python3 -m pip install -r requirements.txt`。
运行 `python3 -m source.app --port 8765` 后，打开 http://127.0.0.1:8765/。详细入口、字段及演练阶段见 [来源契约](docs/source-contract.md)。服务仅监听回环地址；重启后来源回到第一阶段、模拟接收记录清空。业务程序自己的持久状态应另行保管。
## 检查现有来源
执行 `python3 -m unittest discover -s tests -v` 检查来源提供的操作与传输边界，执行 `python3 -m compileall -q source tests` 检查 Python 源码。
这些检查只验证现有来源可访问及模拟接收方自身行为，不代表尚未实现的采集业务已通过。后续产品的使用入口、状态与结果格式由开发者确定，并补充与产品一致的测试和说明。
